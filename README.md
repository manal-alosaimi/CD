## طريقة الرفع على GitHub Pages

1. أنشئي مستودعاً جديداً (New repository) باسم `children-day`، واجعليه **Public**.
2. اضغطي **Add file ← Upload files**، وارفعي الملفات الخمسة كلها، ثم **Commit changes**.
3. اذهبي إلى **Settings ← Pages**، وتحت **Branch** اختاري `main` ومجلد `/ (root)` ثم **Save**.
4. بعد دقيقة أو دقيقتين يظهر رابط المنصة بهذا الشكل:
   `https://اسم-المستخدم.github.io/children-day/`

## صورة الرابط (مهم)

عشان تطلع صورة اليوم العالمي للطفل مع الرابط لما ترسلينه:
افتحي `index.html` في GitHub (زر القلم ✏️)، وغيّري الكلمة `YOUR-USERNAME` في ٣ أماكن إلى اسم المستخدم حقك في GitHub، ثم احفظي.

## ملاحظة

على GitHub تُحفظ بالونات الأطفال على الجهاز اللي أُضيفت منه. فالأفضل تستخدمين المنصة في الفصل على جهاز واحد (جهاز المعلمة أو السبورة الذكية)، والأطفال يضيفون بالوناتهم عليه.
